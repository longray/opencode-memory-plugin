## 一、NetworkChecker 详细规格

### 1.1 核心职责

NetworkChecker 是网络健康检查组件，负责：

- **定时检查外部包装服务的健康状态**：每分钟（默认）调用外部服务的健康检查接口
- **返回综合健康状态**：提供 wrapper、surrealdb、embedding 三个服务的健康状态
- **记录健康检查历史**：维护状态历史，便于故障排查

### 1.2 类结构

```javascript
// lib/network-checker.js

  constructor(options = {}) {
    this.config = {
      checkIntervalMs: options.checkIntervalMs || 60000, // 默认 1 分钟
      wrapperUrl: options.wrapperUrl || "http://localhost:3001",
      timeoutMs: options.timeoutMs || 5000,
    };

    this.lastStatus = null; // 最后的健康状态
    this.statusHistory = []; // 健康状态历史
    this.checkTimer = null; // 定时器

  }

  // 启动定时检查
  start(onStatusChange) {
    /* ... */
  }

  // 停止定时检查
  stop() {
    /* ... */
  }

  // 执行健康检查
  async check() {
    /* ... */
  }

  // 获取当前健康状态

    return this.lastStatus;
  }

    return this.lastStatus?.overall === "healthy";
  }
}
```

### 1.3 健康检查流程

```

     ↓

     ↓
┌──────────────────────────────────────┐
│         响应处理                     │
├──────────────────────────────────────┤
│ HTTP 200 → 解析 JSON               │
│           ↓                          │
│         更新状态缓存                │
│           ↓                          │
│         触发回调                    │
│                                      │
│ HTTP error → 标记为 unhealthy       │
│           ↓                          │
│         更新状态缓存                │
│           ↓                          │
│         触发回调                    │
└──────────────────────────────────────┘
     ↓
返回 HealthStatus 对象
```

## 二、WrapperClient 详细规格

### 2.1 核心职责

WrapperClient 是 HTTP 客户端组件，负责：

- **作为 HTTP 客户端调用外部 Express Wrapper Service**：提供统一的 HTTP 请求接口
- **提供语义搜索和记忆上传接口**：封装 /api/search 和 /api/upload
- **处理网络异常，返回标准错误**：实现重试机制和错误处理

### 2.2 类结构

```javascript
// lib/wrapper-client.js

export class WrapperClient {
  constructor(options = {}) {
    this.config = {
      baseUrl: options.baseUrl || "http://localhost:3001",
      timeout: options.timeout || 30000,
      retry: options.retry || 3,
      retryDelay: options.retryDelay || 1000,
    };
  }

  /**
   * 语义搜索
   */
  async search({ query, limit = 10, threshold = 0.3, projectTag }) {
    const response = await this.request("/api/search", {
      method: "POST",
      body: {
        query,
        limit,
        threshold,
```

### 2.3 重试机制

```javascript
async request(endpoint, options = {}) {
  const { method = 'GET', body } = options;

  for (let attempt = 0; attempt < this.config.retry; attempt++) {
    try {
      const response = await fetch(
        `${this.config.baseUrl}${endpoint}`,
        { method, body: JSON.stringify(body), signal }
      );

      if (!response.ok) throw new Error(`HTTP ${response.status}`);

      return await response.json();

    } catch (error) {
      // 非网络错误不重试
      if (!error.message.includes('network')) throw error;

      // 等待后重试
      if (attempt < this.config.retry - 1) {
        await this.delay(this.config.retryDelay);
      }
    }
  }

  throw lastError;
}
```

```javascript
async execute(args) {
  try {
    const { force } = args;

    // 检查网络健康状态
    const networkChecker = new NetworkChecker();
    if (!networkChecker.isHealthy()) {
      return `❌ Network unavailable. Cannot rebuild remote index.`;
    }

    // 获取待上传的记忆
    const memoryManager = new MemoryManager();
    const entries = await memoryManager.getUnuploadedEntries();

    if (entries.length === 0) {
      return `✅ No unuploaded entries found`;
    }

    // 使用 WrapperClient 批量上传
    const wrapperClient = new WrapperClient();
    const result = await wrapperClient.batchUpload(entries);

    let output = `🔄 Uploading ${entries.length} memory entries to remote index...
`;
    if (result.success) {
      output += `\n✅ Successfully uploaded ${result.count} entries`;
      if (result.failed.length > 0) {
        output += `\n⚠️ Failed to upload ${result.failed.length} entries`;
      }

      // 标记为已上传
      const ids = entries.map(e => e.id).slice(0, result.count);
      await memoryManager.markAsUploaded(ids, { success: true });
    } else {
      output += `\n❌ Upload failed`;
    }

    return output;
  } catch (e) {
    return `❌ Error uploading to remote index: ${e.message}`;
  }
```

## 六、总结

### 6.1 核心变更

1. **新增组件**:
   - MemoryManager - 记忆管理和标签
   - NetworkChecker - 网络健康检查
   - WrapperClient - HTTP 客户端

2. **修改工具**:
   - memory_write - 添加默认标签
   - vector_memory_search - 使用远程 API
   - rebuild_index - 上传记忆到远程
   - index_status - 集成网络状态

3. **移除依赖**:
   - better-sqlite3
   - sqlite-vec

### 6.2 优势

- ✅ **本地优先**: 所有记忆保存在本地，外部服务不可用时不影响
- ✅ **语义搜索**: 使用 SurrealDB 和嵌入服务，提供更好的搜索体验
- ✅ **自动降级**: 网络异常时自动降级到本地搜索
- ✅ **项目分类**: 自动分类记忆为全局或项目特定
- ✅ **批量上传**: 支持批量上传，提高效率
