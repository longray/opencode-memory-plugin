## 🔬 技术细节

### RRF融合算法

```
score = Σ 1/(k + rank)
```

**优点**:
- 零样本，无需归一化
- 对长尾分布不敏感
- 简单高效，性能最佳

**参数调优**:
- k值越小，区分度越高（推荐20）
- k值越大，分数越平滑（避免>120）

### 动态权重策略

| 查询长度 | 向量权重 | BM25权重 | 说明 |
|----------|----------|----------|------|
| ≤2词 | 0.3 | 0.7 | 短查询重关键词 |
| 3-4词 | 0.5 | 0.5 | 均衡权重 |
| >5词 | 0.7 | 0.3 | 长查询重语义 |

### 温和版乘法融合

```
final_score = 0.5*norm_vector + 0.3*norm_bm25 + 0.2*norm_vector*norm_bm25
```

**归一化方法**: 对数压缩（softmax-like）
```
norm_score = log1p(score*9) / log1p(9)
```
