## 下一步计划

### Phase 5: 功能完善（2-3周）

#### Week 5: 自动触发实现

**目标**: 解决痛点1（无自动触发）

**任务**:

1. 实现文件系统监听（chokidar）
2. 集成 OpenCode 事件监听（如可用）
3. 300ms防抖 + 批量处理
4. 配置开关（默认开启）

**验收标准**:

- 保存文件后自动触发分析
- 快速连续保存只触发一次
- 可通过配置禁用

#### Week 6: 多语言支持

**目标**: 解决痛点2（仅支持JS/TS）

**任务**:

1. 实现 Tree-sitter 降级链
2. 支持 Python/Go/Rust/Java 基础分析
3. 语言检测自动切换

**验收标准**:

- Python/Go/Rust/Java 文件可分析
- 自动选择正确的解析器
- 输出格式统一

#### Week 7: 输出优化 + 记忆集成

**目标**: 解决痛点3、4（可视化、记忆保存）

**任务**:

1. 添加格式化输出选项（表格、树形）
2. 集成 memory_write 自动保存
3. 添加项目上下文信息

**验收标准**:

- 支持人类可读的输出格式
- 分析结果自动保存到记忆系统
- 包含项目、文件关系等上下文
