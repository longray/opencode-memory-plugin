## 🔧 需要后端团队支持

### 1. 增量同步 API (BL-P-6 阻塞)

**需求**: 代码指纹增量同步接口

```
POST /api/v1/sync/code-fingerprints
Request: {
  "fingerprints": [
    {"file": "path/to/file.js", "content_hash": "sha256", "symbols_hash": "sha256"}
  ]
}
Response: {
  "changed_files": ["path/to/file.js"],
  "unchanged_files": ["path/to/other.js"]
}
```

**用途**: 只上传变更文件，减少 90% 数据传输

### 2. PrecomputeService API (BL-P-8 阻塞)

**需求**: 代码分析结果上传接口

```
POST /api/v1/precompute/analysis
Request: {
  "project_id": "xxx",
  "files": [...],
  "symbols": [...],
  "relations": [...]
}
Response: {
  "memory_ids": {"file1": "mem-xxx", ...},
  "status": "success"
}
```

**用途**: 上传代码分析结果，创建调用关系

### 3. 集成测试环境 (BL-P-11 阻塞)

**需求**: 可访问的 v3.2 后端服务

- 端口: 18008
- 功能: WebSocket、HTTP API、Meilisearch
- 数据: 测试租户和项目
