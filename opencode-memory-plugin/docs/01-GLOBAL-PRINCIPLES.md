## 📖 1.1 适用范围

### 1.1.1 项目类型

本文档适用于 **OpenCode Memory Plugin** 项目，这是一个：

- **Node.js ES Module 项目** - 使用现代 JavaScript (ES2022+)
- **OpenCode 插件** - 为 OpenCode AI 助手提供持久化记忆功能
- **多组件架构** - 包含核心库、CLI工具、安装脚本

### 1.1.2 适用团队

- **核心开发者** - 插件功能开发和维护
- **贡献者** - 通过 PR 提交代码改进
- **用户开发者** - 基于插件进行二次开发

## 🎯 1.2 核心原则

### 1.2.1 自动化原则

| 原则           | 说明                     | 实施方式                           |
| -------------- | ------------------------ | ---------------------------------- |
| **检查自动化** | 所有检查通过工具自动执行 | Pre-commit hooks, CI/CD            |
| **修复自动化** | 常见问题自动修复         | `eslint --fix`, `prettier --write` |
| **反馈即时性** | 开发者提交前发现问题     | Pre-commit hook 拦截提交           |
| **全量覆盖**   | 代码检查覆盖所有文件     | `--all-files`                      |

### 1.2.2 统一性原则

| 原则         | 说明                 | 实施方式               |
| ------------ | -------------------- | ---------------------- |
| **工具统一** | 全团队使用相同工具链 | ESLint + Prettier      |
| **配置统一** | 配置文件统一管理     | 项目根目录配置         |
| **风格统一** | 代码风格保持一致     | EditorConfig, Prettier |
| **输出统一** | 错误输出格式统一     | 统一日志格式           |

### 1.2.3 安全性原则

| 原则         | 说明             | 实施方式              |
| ------------ | ---------------- | --------------------- |
| **密钥防护** | 防止敏感信息泄露 | Gitleaks 密钥检测     |
| **代码安全** | 扫描常见安全漏洞 | ESLint security rules |
| **依赖安全** | 检查依赖漏洞     | `npm audit`           |

**安全等级**:

- **P0**: 必须通过 - 阻止提交/部署（密钥泄露）
- **P1**: 强烈建议 - 阻止提交（高危漏洞）
- **P2**: 建议修复 - 警告但不阻止（代码异味）
- **P3**: 可选修复 - 信息性提示（风格问题）

---

## 📊 1.3 优先级体系

| 优先级 | 类别       | 说明               | 违规后果             |
| ------ | ---------- | ------------------ | -------------------- |
| **P0** | 安全扫描   | 必须通过，阻止提交 | 密钥泄露、安全漏洞   |
| **P1** | 类型检查   | 强烈建议通过       | 类型错误、未定义变量 |
| **P2** | 代码格式化 | 自动修复，可豁免   | 格式不一致           |
| **P3** | 代码检查   | 警告级别，建议修复 | 代码异味、复杂度     |
| **P4** | 测试覆盖   | 阶段性目标         | 覆盖率不足           |
| **P5** | 文档规范   | 辅助性要求         | 注释不完整           |

## 🛠️ 1.4 工具链概览

### 1.4.1 核心工具

| 工具             | 用途                        | 配置文件                  |
| ---------------- | --------------------------- | ------------------------- |
| **ESLint**       | JavaScript/Node.js 代码检查 | `.eslintrc.cjs`           |
| **Prettier**     | 代码格式化                  | `.prettierrc`             |
| **EditorConfig** | 编辑器统一配置              | `.editorconfig`           |
| **Gitleaks**     | 密钥泄露检测                | `.gitleaks.toml`          |
| **Pre-commit**   | Git hooks 管理              | `.pre-commit-config.yaml` |

### 1.4.2 工具版本要求

```json
{
  "devDependencies": {
    "eslint": "^8.57.0",
    "prettier": "^3.2.5",
    "husky": "^9.0.11",
    "lint-staged": "^15.2.2"
  }
}
```

## 📝 1.5 文档使用方式

1. **阅读本文档** - 了解完整规范体系
2. **查看配置模板** - 参考 `11-TOOLCHAIN-TEMPLATES.md`
3. **安装工具** - 运行 `npm install` 安装依赖
4. **初始化 hooks** - 运行 `pre-commit install`
5. **验证配置** - 运行 `pre-commit run --all-files`
