**`updateLocalEntry()` 实现** (行 821-891):
- 读取文件内容
- 根据 Memory ID 或 Source ID 定位条目
- 用新内容替换旧条目
- 写回磁盘
- 新增 `formatEntryForMarkdown()` 辅助函数

**`deleteEntries()` 实现** (行 388-423):
- 解析文件获取所有条目
- 调用后端 `client.delete()` API 删除每个条目
- 可选删除本地文件 (`removeFile` 选项)
- 返回成功/失败计数
