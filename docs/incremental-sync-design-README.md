## ⚠️ 关键决策点

### 1. ID生成策略

**决策**：SurrealDB生成record_id，插件端存储  
**理由**：全局唯一、时间排序、避免冲突  
**影响**：首次上传时需要等待后端返回ID

### 2. 操作分离 vs 混合UPSERT

**决策**：显式分离CREATE/UPDATE/DELETE  
**理由**：逻辑清晰、性能最优、便于优化  
**影响**：代码稍长，但可维护性更好

### 3. Checkpoint格式

**决策**：JSONL格式（追加写入）  
**理由**：崩溃恢复、易于压缩、性能好  
**影响**：需要定期压缩（>1MB时）

### 4. 删除保护

**决策**：20%或50条阈值  
**理由**：防止误删大量数据  
**影响**：大量删除时需要--force确认

### 5. Outbox模式

**决策**：P1功能，强烈建议实现  
**理由**：保证跨存储一致性  
**影响**：增加4小时工时，但提高可靠性
