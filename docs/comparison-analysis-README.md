## 🔥 最严重的问题（必须立即修正）

### 1. 数据模型缺失关键字段

**问题**：设计文档的MemoryEntry缺少4个必需字段

| 缺失字段       | 影响                                |
| -------------- | ----------------------------------- |
| `embedding`    | ❌ 无法进行语义搜索（核心功能丧失） |
| `tenant_id`    | ❌ 多租户数据混乱（安全风险）       |
| `project_id`   | ❌ 项目隔离失效（数据混乱）         |
| `content_hash` | ⚠️ 快速去重性能下降                 |

**修正**：在设计文档中添加这些字段

### 2. 缺少核心API

**问题**：无法实现增量同步

| 缺失API                            | 影响            |
| ---------------------------------- | --------------- |
| `POST /api/v1/memories/batch-sync` | ❌ 无法增量同步 |
| `GET /api/v1/memories/source_ids`  | ❌ 无法对比差异 |
| `PATCH /api/v1/memories/{id}`      | ❌ 无法更新记忆 |
| `DELETE /api/v1/memories/{id}`     | ❌ 无法删除记忆 |

**修正**：实现这些API

### 3. 缺少关键机制

**问题**：无法追踪同步状态

| 缺失机制   | 影响                      |
| ---------- | ------------------------- |
| 变更检测   | ❌ 无法识别新增/更新/删除 |
| Checkpoint | ❌ 无法追踪同步状态       |
| 幂等性     | ❌ 重复上传风险           |
| 并发控制   | ❌ 数据覆盖风险           |

**修正**：实现这些机制

### MemoryEntry（修正版）

```typescript
interface MemoryEntry {
  // 核心内容
  content: string;
  type: string;
  tags: string[];

  // 指纹和哈希
  source_fingerprint: string; // 新增
  content_hash: string; // 保留

  // 多租户和项目
  tenant_id: string; // 保留（必需）
  project_id: string; // 保留（必需）

  // 向量
  embedding: number[]; // 保留（必需）

  // 来源
  source: string; // 保留（必需）

  // 元数据（灵活结构）
  metadata: {
    [key: string]: any; // 允许任意字段
  };

  // 可选字段
  source_id?: string;
  source_timestamp?: string;
  classification_confidence?: number;
}
```
