## 🚨 遇到的问题

### 1. API限流错误（429 Too Many Requests）

**错误信息**:
```
Real embedding API error: API error: 429 Too Many Requests
```

**影响**:
- ❌ 大量API调用失败
- ❌ 降级到Mock模式（但仍然消耗API配额）
- ❌ 测试速度严重受影响
- ❌ API Key消耗量大（可能产生费用）

### 2. 限流原因分析

**可能原因**:
1. 短时间内大量并发请求
2. 超过免费配额
3. 检测到异常请求模式
4. ModelScope API免费层限制

**当前请求模式**:
- 20条数据并发写入
- 10个单个embedding生成
- 5个不同搜索请求
- 频率：~50-100请求/秒
